Exoplanet Explorer 🌌

An interactive React-based web application for exploring, searching, and visualizing exoplanet data using modern UI components and API integration. The project provides an engaging space-themed interface where users can discover known exoplanets, classify planetary characteristics, and interact with animated visualizations.

🚀 Features
🔭 Search and explore known exoplanets
🪐 Planet classification system
🌌 Interactive space-themed UI
⚡ Fast and responsive React frontend
📡 API integration for exoplanet data
🎨 Modular component architecture
✨ Animated and visually appealing interface
🧩 Reusable React components
🌍 Responsive design for multiple screen sizes

🛠️ Tech Stack
⚛️ React.js
🎨 CSS3
📡 REST API Integration
🚀 Vite
🌌 Three.js / React Three Fiber (if used in Scene.jsx)
📦 Installation

🌍 Usage
Open the application in your browser.
Search for known exoplanets.
Explore planetary data and classifications.
Interact with the animated UI and visual components.
🧠 Core Components
🔎 KnownPlanetSearch

Allows users to search and retrieve information about known exoplanets.

🪐 ClassifyPlanet

Classifies planets based on planetary characteristics and data.

🌌 ExoplanetViewer

Displays detailed exoplanet information and visual representation.

🎥 Scene

Handles animated or 3D visual rendering for immersive user experience.
